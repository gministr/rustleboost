# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

To report a security vulnerability, contact us privately:

- Telegram: [@rustlevpn_support](https://t.me/rustlevpn_support)

We will respond within 48 hours and work to release a fix as quickly as possible.

## Security Features

- **TUN mode** uses WinTun driver, requires administrator privileges
- **No telemetry** — RustleBoost does not send any data to our servers
- **Open source** — all code is publicly auditable on GitHub
- **sing-box** — uses the well-audited sing-box VPN core
